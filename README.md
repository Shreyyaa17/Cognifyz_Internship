# 🌐 Interactive Website - Cognifyz Internship Project

A complete front-end development project built as part of the **Cognifyz Internship Program (Level 1 to Level 4)** — showcasing skills from basic HTML to advanced CSS preprocessing and API integration.

---

## 🚀 Project Overview

This responsive and interactive website demonstrates various front-end techniques such as:

- ✅ **HTML Structure**: Semantic layout, headings, paragraphs, images
- 🎨 **Styling with Inline CSS**
- 📱 **Responsive Design**: Media queries for screen adaptability
- 🖱️ **JavaScript Interactivity**: Event handling and dynamic behavior
- 🌐 **API Integration**: Fetch and render dynamic data from JSONPlaceholder
- 📝 **Form Design & Validation**: CSS styling and input checks
- ⚙️ **Component-Based Design with Bootstrap**
- 🧩 **Advanced Styling with SASS**: Variables, nesting, and modularity

---

## 🛠️ Technologies Used

- HTML5  
- CSS3  
- JavaScript (ES6)  
- Bootstrap 5  
- Sass (CSS Preprocessor)  
- JSONPlaceholder API  

---

## 📌 Features Implemented

### Level 1: Beginner
- Basic HTML setup
- Inline CSS styling

### Level 2: Intermediate
- Responsive layout using media queries
- Interactive button using JavaScript

### Level 3: Advanced
- API data fetch from JSONPlaceholder
- DOM manipulation to display fetched data
- Form creation with client-side validation

### Level 4: Expert
- Bootstrap-based component styling
- SASS for reusable and maintainable CSS
